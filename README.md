# Credo Web

კრედო ბანკის ვებგვერდი, აწყობილი Figma-ს დიზაინის მიხედვით — **Next.js 15**, **React 19**, **TypeScript** და CSS Modules.

## გვერდები

| მისამართი | აღწერა |
| --- | --- |
| `/` | მთავარი გვერდი |
| `/loans` | სესხები |
| `/loans/digital-loan` | ციფრული სესხი |
| `/rcheuli` | კრედო რჩეული (მუქი თემა) |

## მოთხოვნები

- [Node.js](https://nodejs.org/) **20** ან უფრო ახალი (შემოწმებულია Node 24-ზე)
- npm (Node.js-თან ერთად ყენდება)

ვერსიის შესამოწმებლად:

```bash
node -v
npm -v
```

## ლოკალურად გაშვება

1. რეპოს ჩამოტვირთვა:

   ```bash
   git clone https://github.com/Hellstaber/credo-web.git
   cd credo-web
   ```

2. დამოკიდებულებების დაყენება:

   ```bash
   npm install
   ```

3. დეველოპმენტ სერვერის გაშვება:

   ```bash
   npm run dev
   ```

4. გახსენით ბრაუზერში [http://localhost:3000](http://localhost:3000)

ფაილების შეცვლისას გვერდი ავტომატურად ახლდება.

## npm ბრძანებები

| ბრძანება | რას აკეთებს |
| --- | --- |
| `npm run dev` | დეველოპმენტ სერვერი (Turbopack) — `http://localhost:3000` |
| `npm run build` | production build-ის აწყობა `.next` საქაღალდეში |
| `npm run start` | აწყობილი production ვერსიის გაშვება (ჯერ `npm run build`) |

production ვერსიის ლოკალურად შესამოწმებლად:

```bash
npm run build
npm run start
```

## პროექტის სტრუქტურა

```
app/            გვერდები (Next.js App Router) და გლობალური სტილები
components/     სექციები და კომპონენტები, თითოეულს თავისი .module.css
data/           მენიუს და სიახლეების მონაცემები
lib/            ანიმაციის ძრავები (გლობუსი, ნაწილაკები, სიახლეების კარუსელი)
public/         სურათები, ხატულები და სხვა სტატიკური ფაილები
```

## დიზაინის ტოკენები და თემა

ფერები და ზომები Figma-ს ცვლადებიდანაა და `app/globals.css`-ში CSS ცვლადებადაა გატანილი.
მუქი თემისთვის ელემენტს (ან მთელ გვერდს) დაუმატეთ `data-theme="dark"` — ასე მუშაობს `/rcheuli` გვერდი.

## Vercel-ზე ატვირთვა

1. გახსენით [vercel.com/new](https://vercel.com/new) და შედით GitHub ანგარიშით.
2. აირჩიეთ `credo-web` რეპო → **Import**.
3. Framework Preset ავტომატურად იქნება **Next.js** — დამატებითი პარამეტრები არ სჭირდება.
4. **Deploy**.

ამის შემდეგ ყოველი `git push` `main` ბრანჩზე საიტს ავტომატურად განაახლებს.

## შენიშვნები

- **შრიფტი:** დიზაინი იყენებს Helvetica Neue-ს ქართულ ვერსიას. თუ კომპიუტერზე არ არის დაყენებული, ქართული ტექსტი Noto Sans Georgian-ით ჩანს.
- **OneDrive:** თუ პროექტი OneDrive-ის საქაღალდეშია და `npm run dev` `EBUSY` შეცდომას აგდებს, სინქრონიზაცია `.next` საქაღალდეს ბლოკავს — გადაიტანეთ პროექტი OneDrive-ის გარეთ ან შეაჩერეთ სინქრონიზაცია.
- **სტატიკური მონაცემები:** ვალუტის კურსი, ფილიალების რუკა და სიახლეები ჯერ დიზაინის/ფიქსირებული მონაცემებია და API-სთან არ არის დაკავშირებული.
